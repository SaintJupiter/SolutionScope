# Current capabilities

The platform currently supports document upload, paragraph-level indexing, and source-linked answer review.

The platform currently supports role-based access to approved project folders.

# Planned capabilities

The next version will add cross-document conflict detection and version comparison.

# Candidate ideas

The product team could add automated approval routing after the review workflow is validated.

# Acceptance requirements

Every generated factual statement must retain an exact source locator and a reviewer-visible lifecycle state.

The acceptance document does not define a maximum review time or an allowed unsupported-claim rate.
