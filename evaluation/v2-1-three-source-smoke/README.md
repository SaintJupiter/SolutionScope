# SolutionScope v2.1 三方覆盖与变更影响自测

本目录使用脱敏合成材料验证两种普通 RAG 难以直接完成的产品动作：

1. 分别登记要求、方案和验收证据，不允许三类证据互相替代；
2. 将复合要求拆为动作、条件、指标和验收组件，并由确定性门禁派生放行结论；
3. 当要求版本发生变化时，冻结旧结论并生成方案、验收和人工确认的复核清单。

样例故意设置了两处“相关材料齐全但仍不能放行”的情况：方案没有承诺识别率 92%，也没有承诺时延 600 ms。验收材料中出现相同数字不能替方案补写能力。

变更样例随后把识别率要求从 92% 提升到 95%。系统不沿用旧覆盖状态，而是将该项标记为 `modified`，关闭放行并要求重新检查方案响应和验收计划。

本目录是确定性工程自测，不是语义准确率、专家金标或泛化证据。
